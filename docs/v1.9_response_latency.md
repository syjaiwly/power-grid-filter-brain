# v1.9 — Detection latency study

## Goal
Optimize APF detection latency without allowing short windows to mistake pollution for the 50 Hz fundamental state.

## Baseline experiment
- Grid: 50 Hz, 220 V RMS phase / 380 V line-line
- Control sample rate: 20 kHz (0.05 ms/sample)
- Test disturbance: 250 Hz harmonic amplitude step, 1 A peak -> 4 A peak at 60 ms
- Inner-loop equivalent bandwidth: 1.5 kHz
- Causal one-sample command delay
- Harmonic amplitude estimated with a one-cycle I/Q window in the baseline detector

## Result
The baseline detector/control chain shows a 10–90% response of about 2.70 ms and reaches the ±10% band at about 3.50 ms.

## Design direction
v1.9 should compare causal half-cycle, one-cycle, and adaptive/multi-rate detection. The objective is not simply the shortest window: minimize total detection + computation + control delay while preserving protection of the true 50 Hz state.

## Acceptance metrics
1. Detection latency (ms)
2. 10–90% compensation response (ms)
3. Settling time (ms)
4. Harmonic residual RMS / THD
5. False fundamental-change decisions
6. CPU/sample computational load
7. Behavior under abrupt load and harmonic changes

## Engineering rule
Every algorithm revision must report both cleaning performance and dynamic response. A cleaner waveform with materially worse response is not automatically an improvement.
